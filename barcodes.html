Sample barcodes

For App Review. FilmStacks 1.0.

FilmStacks catalogues the films you own on physical disc, and the way you add one is to point the camera at the barcode on the case. This page exists so the app can be assessed without a DVD or Blu-ray case to hand: every code below is a real retail disc barcode that FilmStacks identifies.

How to use this page. Open it on a second screen - a Mac, another phone, or print it - then launch FilmStacks, tap the Scan tab, allow the camera, and hold the device 15 to 25 cm from one of the barcodes below. Raise the screen brightness if a code will not read. Work down the page in order; the last one is a repeat on purpose.

Two notes. The device needs a network connection for these, because the film is identified from a barcode map we host rather than from a database shipped inside the app. And to see the shelf placement feature, draw a cabinet on the Shelves tab first, which takes about fifteen seconds: the second question on every add card then offers its squares.

Now scan the first code a second time

The same barcode again, after it has been added. The app answers "Already on your shelf" and refuses the add, which is the feature the app is most used for: checking in a shop whether the copy in your hand is one you already own.

If a code will not scan

Raise the screen brightness, hold the device further back, and keep the whole symbol including the white margins inside the frame. There are also two paths that need no barcode at all: Type it inside the scanner takes a code by hand, and the + button on the Library tab searches for any film by name.

About these codes

They are retail barcodes for commercially published discs, read straight out of the map that serves the app, so they stay valid for as long as this page is published. Film titles and artwork inside the app come from The Movie Database; FilmStacks is not endorsed or certified by TMDB. No poster artwork is reproduced on this page.
